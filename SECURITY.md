# 🔐 Security Policy – TrendCart

## 🛡 Supported Versions

TrendCart is actively maintained on the latest stable release.

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes |
| Older versions | ❌ No |

Security updates are provided only for the latest version.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in **TrendCart**, please report it responsibly.

### 📩 How to Report

- Open a **private security advisory** on GitHub  
OR  
- Email: your-email@example.com

(Replace the email above with your real contact email.)

---

## 📌 What to Include in Your Report

Please provide:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Expected vs actual behavior
- Screenshots or proof-of-concept (if applicable)
- Potential impact of the issue

---

## ⏱ Response Timeline

- Initial response within **48 hours**
- Status update within **3–5 business days**
- Verified issues will be fixed as soon as possible

---

## 🔒 Responsible Disclosure

We kindly request that you:

- Do NOT publicly disclose the vulnerability before it is resolved
- Do NOT exploit the vulnerability beyond what is necessary to demonstrate it
- Allow reasonable time for a fix before public discussion

We appreciate responsible security research.

---

## 🔐 Infrastructure Security

TrendCart uses:

- Firebase Authentication
- Firestore Database
- Firebase Hosting

All database access is protected by Firestore security rules.
Unauthorized access attempts are monitored and restricted.

---

## ⚠️ Scope

This security policy applies only to:

- The official TrendCart repository
- Official deployments managed by the project owner

Third-party services follow their own security policies.
